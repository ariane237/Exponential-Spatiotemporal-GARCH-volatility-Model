# Exponential-Spatiotemporal-GARCH-volatility-Model
Code and examples for the simulation and estimation of Exponential Spatiotemporal GARCH volatility Model. For further details on the theoretical background and applications of the model, we refer to our arXiv discussion paper "https://doi.org/10.48550/arXiv.2511.05126" by Ariane N. Meli Chrisko, Philipp Otto, Wolfgang Schmid
